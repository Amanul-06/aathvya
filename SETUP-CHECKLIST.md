# Setup checklist

- [ ] Copy `.env.example` to `.env.local`
- [ ] Add Shopify store domain and Storefront API token locally
- [ ] Publish products and collections to the Headless sales channel
- [ ] Run `npm install`
- [ ] Run `npm run dev`
- [ ] Test a product variant, add-to-bag, quantity controls and Shopify checkout
- [ ] Replace sample Unsplash imagery with approved House of Aathvya photography
- [ ] Add real customer-service email, shipping, returns, privacy and terms pages before launch
